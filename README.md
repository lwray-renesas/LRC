# LRC

**Target Devices:** `RA0E1 & PC`  

---

## Overview

LRC stands for light-weight residual current and it is a middleware containing core services for measuring current in an AC system for the purposes of RCD's. Core functions include measurements current for single and multi-phase systems & event detection/reaction (e.g., over current).
It's primary focus is in applications such as RCD's and other current monitoring systems and as such these take focus in any descriptive material and direction for the example projects.
