Mathematics

This page outlines the key mathematical concepts and signal‑processing foundations used in residual current detection.

Unlike energy metering, which focuses on long‑term accurate measurement, RCD mathematics prioritises:

  • Fast detection of fault current
  • Robust operation under noise and distortion
  • Predictable time‑domain behaviour

Context

Residual current detection begins with the acquisition of instantaneous samples from an analog front‑end or ADC subsystem.

We begin with a continuous‑time signal representing residual current:

\[ i_\Delta(t) \]

Which is sampled discretely by the ADC:

\[ I_{\Delta,\mathrm{adc}}[n] \]

Where:

  • \( n \) denotes the sample index
  • \( T_s \) is the sampling period

This signal represents the instantaneous residual current waveform, from which further processing derives trip metrics such as RMS value,

Residual Current

Residual current is defined as the vector sum of all live conductors supplying a load.

For a single‑phase system:

\[ i_\Delta(t) = i_L(t) - i_N(t) \]

For multi‑phase systems:

\[ i_\Delta(t) = \sum_{k=1}^{M} i_k(t) \]

Under normal operating conditions:

\[ i_\Delta(t) \approx 0 \]

A non‑zero residual current indicates leakage to earth and may represent a hazardous condition.

RMS Evaluation

In many RCD standards, trip thresholds are specified using the RMS value of the residual current**.

The RMS value of a discrete residual current signal is:

\[ I_{\Delta,\mathrm{RMS}} = \sqrt{ \frac{1}{N} \sum_{n=0}^{N-1} \left(I_{\Delta,\mathrm{adc}}[n]\right)^2 } \]

Where:

  • \( N \) is the number of samples within the evaluation window
Remarks
RCD evaluation windows are typically short and tightly bounded to guarantee compliance with maximum disconnection times.

Windowed RMS

Windowed RMS evaluates the signal over a sliding time window that advances sample by sample.

Given the above definition of RMS but using the windowed apprroach, we can divide the operation for computino of RMS into:

The sum of squares:

\[S[n] = \sum_{k=n-N+1}^{n} \left(i_\Delta[k]\right)^2 \]

Where:

  • \( N \) is the window length in samples.
  • \( n \) is the current sample (or time period).
  • \( k \) is the oldest sample in the window, to be removed.
  • \( S[n] \) is the sum of all sqaures in the window ( \( k \) to \( n \)) at time/sample n.

And the RMS:

\[I_{\Delta,\mathrm{RMS}}[n] = \sqrt{\frac{S[n]}{N}} \]

Where:

  • \( I_{\Delta,\mathrm{RMS}}[n] \) is the RMS at time/sample n.=

So rather than recomputing from scratch, we can instead keep the sum of squares recorded & the window of squared samples and simply subtract the oldest squared sample in the window and add the newest squared sample to recompute the sum of squares and thus the RMS at each sample n.

\[S[n] = S[n-1] + \left(i_\Delta[n]\right)^2 - \left(i_\Delta[k]\right)^2 \]

That is:

  • The square of the newest sample entering the window is added
  • The square of the oldest sample leaving the window is subtracted
  • This is done on the running sum of squares ( \( S[n-1] \))

This produces an exact sliding‑window RMS with constant execution time.

Advantages

  • Fast detection of residual current faults
  • Well‑defined response time
  • Suitable for short regulatory trip windows
  • Easily correlated with time‑based trip curves

Considerations

  • Requires careful window length selection
  • Smaller windows are noisier
  • Larger windows increase detection latency
  • Windows consume memory in an MCU
Remarks
A consideration must be taken when selecting the window length, if the window length if not aligned closely to an integer number of line cycles - ripple in the computed RMS is observed.

Time‑Domain Considerations

Unlike metering systems, an RCD must respond correctly to:

  • Transient residual currents
  • Non‑sinusoidal waveforms
  • Pulsating and smooth DC components

Therefore, time‑domain behaviour is just as important as magnitude.

Typical parameters of interest include:

  • Time above threshold
  • Rate of rise of residual current
  • Energy content within a time window

Filtering

Filtering is used to improve signal robustness while preserving fault detection performance.

High‑Pass Filtering (DC Rejection)

High‑pass filtering removes DC offsets introduced by:

  • Amplifier input bias
  • ADC offset
  • Integration drift (Rogowski sensors)

A first‑order digital HPF can be written as:

\[ y[n] = \alpha \, y[n-1] + \alpha (x[n] - x[n-1]) \]

With:

\[ \alpha = \frac{1}{1 + 2\pi f_c T_s} \]

Where:

  • \( f_c \) = high‑pass cut‑off frequency
  • \( T_s \) = sampling period
Remarks
In RCD designs, \( f_c \) is chosen to remove offset without attenuating 50/60 Hz components relevant to fault detection.

Low‑Pass Filtering (Noise Suppression)

Low‑pass filtering attenuates high‑frequency noise that could:

  • Cause false trips
  • Interfere with comparators
  • Degrade numerical stability

A first‑order digital LPF is commonly expressed as:

\[ y[n] = \alpha x[n] + (1 - \alpha) y[n-1] \]

Where:

\[ \alpha = \frac{2\pi f_c T_s}{1 + 2\pi f_c T_s} \]

Remarks
LPF bandwidth selection directly affects trip latency and must be validated against regulatory time limits.

Trip Decision Metrics

RCD trip decisions are typically based on one or more of the following metrics:

  • RMS residual current exceeding \( I_{\Delta n} \)
  • Instantaneous magnitude exceeding threshold
  • Integrated current exceeding energy‑based limits
  • Time above threshold

These metrics are evaluated against regulatory trip curves that define maximum allowable disconnection times.
