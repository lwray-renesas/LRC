LRC Interrupt Callbacks

The LRC Callbacks are the foundation of LRC's operation, these callbacks are installed in the appropraite interrupts service routines (ISR's) and invoke LRC's core operation.

void LRC_CB_ADC ( void )

ADC CALLBACK - Processes the ADC samples according to the number of measurement channels registered.

The ADC Callback handles:

  1. Sample processing and accumulation.
  2. Event detection & reaction to slow & fast trips according to the configpassed at initialisation.
Note
This function expects all samples to be aligned Q15.16 (32bit signed) format!
RMS is computed using a block-based window (not sliding), with accumulation reset after each window
