LRC Control API

The LRC Control API is used to control the functionality of LRC, that is to say it defines LRC's behaviour. For example starting and stopping operations.

◆ LRC_Deinit()

void LRC_Deinit ( void )

Deinitialises LRC.

Deconstructs the measurement channel linked list so callbacks have no structures to work on.

Warning
Does NOT stop drivers operating - call LRC_Stop first if this is the desired behaviour.
